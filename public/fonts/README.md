LT Superior licensed webfonts

Add licensed WOFF2 files with these exact names:
- lt-superior-regular.woff2 (400)
- lt-superior-medium.woff2 (500)
- lt-superior-semibold.woff2 (600)

Restart Vite or rebuild after adding files. Vite only emits font-face URLs for existing files. No commercial font files are included in this repository. The UI uses a locally installed LT Superior when available, otherwise Poppins.
